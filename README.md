# About us
We are some fellows with smashing intent working on a passion project with passion. 

The goal is to build a fully contained hardware and software AIO application to read, interpret, and display CAN BUS signal output for use with as many compatible automotive ECU's as possible. 

This project will have scalability to attach and function with a triaxial accelerometer, GPS spedometer, lap timer, k-band sensor, cabin temperature sensor, linear shaft encoders, etc.
